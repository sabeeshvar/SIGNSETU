# SignSetu Indian Sign Language Dataset Repository

This folder organizes local training samples and landmark recording captures for the 14 supported prototype gestures in SignSetu.

## Gesture Folders:
- `hello/`: Universal greeting gestures
- `thank_you/`: Expressions of gratitude
- `yes/`: Affirmative fist signs
- `no/`: Horizontal negation gestures
- `help/`: Emergency assistance signs
- `stop/`: Halting vertical palm signs
- `please/`: Polite request gestures
- `good/`: Positive evaluation gestures
- `bad/`: Negative evaluation gestures
- `water/`: Thirst / drinking need signs
- `food/`: Eating / nourishment signs
- `home/`: Domestic / residence signs
- `school/`: Educational place signs
- `hospital/`: Medical care signs

## Adding Samples:
Place captured landmark JSON recordings or CSV feature vectors in the corresponding folder.
